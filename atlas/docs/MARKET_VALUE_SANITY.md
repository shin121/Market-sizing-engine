## 네 경제적 패턴

기준: 큰 인구 ≥ 전체 성인 인구의 3%, 높은 지출 = 음악 참여자 평균보다 높은 연간 지출. 절대 사업성 판정이나 매출 예측이 아니다.

|유형|실제 유형 수|예시|
|---|---:|---|
|Scale Prize|14|영상 탐색 후기검증형|
|Volume Market|1|휴식·보상 실력추구형|
|Premium Niche|32|온라인 탐색 신중구매형|
|Small / Low Spend|5|영상 탐색 정보탐색형|

인구 순위와 지출 순위의 차이는 연령별 참여율·지출 분포 및 관측 행동에 따른 배분에서 나온다. 계수는 추정된 지출 탄력성이 아니므로 순위 역시 추가 검증 대상이다.

## 계산 검증

- 별도 DuckDB 행 조건·가중치·연령/성별 proxy moment로 16개 oracle 사례를 계산하고 서버 bitmap 결과와 대조했다.
- 서로 겹치지 않는 연령 집단의 Base 합이 전체 음악 Base와 일치한다. 전체 금액은 중복 유형 합산으로 구하지 않는다.
- 월/주/연, 가중 평균, 단위 불일치, 범위 순서, 금액 없는 산업, 범위 밖 연령, 빈 교집합, 포맷을 테스트했다.
- 6개 계산 경로는 단위 테스트용 입력으로 검증했으며 UI에 테스트 금액을 공급하지 않는다.
