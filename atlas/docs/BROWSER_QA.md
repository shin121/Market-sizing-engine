검증: 실제 Chromium / agent-browser 0.36.0. 기본 1440×900, 추가 1920×1080 및 390×844. API/엔진 검증과 구분해 실제 링크·검색·버튼·축 선택·브라우저 history를 조작했다.

## 발견한 사업 가설

1. **수집 취향에 맞는 집 정리·전시 서비스**: 계획 중심 수집몰입형 약 130만 명, 집·인테리어 2.36×, 자기표현 1.71×. 보관과 전시를 함께 제공하는 모듈 가구·정리 상품을 조사할 후보다. 실제 구매 전환이나 지불의향은 미확보다.
2. **반려동물 관리 부담을 줄이는 반복 서비스**: 반려동물×번거로움·관리 부담 약 8.5만 명(시장 내 4.7%). 계획 중심 구독 이용형×Pet을 더 좁히면 배달 주문×관리 부담 약 2,900명, 조건부 Index 1.20×, 63개 관측이 있다. 반복 배송·관리 대행의 문제 인터뷰 후보이며, 좁은 조합은 희소하다.
3. **배움과 회복을 함께 고려한 전문 채널 이용**: 배움 중심 전문채널이용형×교육에서 유료 구독서비스 접점×휴식 욕구 약 5,000명, Index 1.26×, 110개 관측. 학습 후 회복이나 쉬운 이용 형식에 대한 가설을 검토할 수 있다. 이 Index는 조건부 연관이며 교육 시장 성장 추세가 아니다.
4. **수집 지식과 커뮤니티 참여를 연결하는 서비스**: 수집 중심 정보탐색형×취미 시장에서 커뮤니티 접점×자기표현 약 5,400명, Index 1.29×, 119개 관측. 큐레이션·작품 소개·경험 공유 기능의 이용 동기를 조사할 후보다.

## 추가 검증

- 전체 검색: 가격, 수집, 전문가, 구독, 반려동물, 육아, 여행, 수집 반려동물. 마지막 검색에서 생성 세그먼트 Dashboard로 진입.
- 집계 데이터: 170개 이상 feature/demographic/related-type 집계행, 표본 수·비중·Index, 새로고침 후 데이터 탭 유지.
- 관계 노드 선택: URL focus 및 동일 페이지의 선택 집단 분석, 전체 교집합 Dashboard 진입.
- 1440×900 전체/유형, 1920×1080 전체, 390×844 유형을 시각 점검. 모바일 문서 너비 390px로 가로 넘침 없음.
- axe-core 4.12.1: 최종 Global Atlas 0 violations, Archetype 0 violations. 일부 SVG 대비는 자동 판별 불가로 시각 확인했다.
- SVG title의 초기 hydration 불일치 2건을 단일 문자열 렌더링으로 수정. 새 브라우저 세션의 최종 오류 목록은 비어 있다.
- 브라우저 실행 로그는 browser-discovery.json; 최종 렌더링/색상 보완은 별도 접근성·스크린샷 증거에 기록했다.

## 한계

이 검증은 탐색 기능과 데이터 일관성을 확인한다. 실제 고객 사용성 연구, 정규화 precision/recall 추정, 제품 수요·사업성 확인을 수행한 것은 아니다. “불편”이 관련 산업 때문에 발생했다는 인과 관계도 입증하지 않는다.

최종 검색 경계 검증: ⌘K로 검색 포커스, 존재하지 않는 검색어의 빈 결과, 영문 Pet 결과, Escape로 닫기까지 확인했다.
