# 외부 소비 기준과 인구 재검증 — v0.4

2026-09-06 개정. 현재 산식과 범위는 이 문서가 v0.3의 음악 전용 범위 및 원 서술 인구 문서보다 우선한다. 원본 추출 자료는 과거 재현 근거로 보존한다.

## 달라진 해석

서술에 ‘후기’나 ‘계획 구매’라는 표현이 없다는 사실로 비이용자를 판정할 수 없다. 기존 2.3만 명과 중첩 3,900명은 실제 행동 인구가 아니라 **합성 서술의 조건 일치를 인구에 투영한 규모**였다. 새 모델은 확보한 조사 비율을 합성 프로필에 연결한다. 이 과정에서 생긴 소속은 관측 표본으로 세지 않는다.

| 보고된 사례 | 원 서술 투영 | 보정 모델 | 원 서술 조건 일치 |
|---|---:|---:|---:|
| 후기 확인 신중구매형 · 전체 | 약 2.3만 명 | 약 1,904만 명 | 501건 |
| 위 유형 AND 온라인 탐색 신중구매형 | 약 3,900명 | 약 1,614만 명 | 84건 |
| 집·인테리어 AND 후기 확인 신중구매형 | 약 4,600명 | 약 325만 명 | 101건 |
| 집·인테리어 AND 위 두 유형 | 약 1,400명 | 약 292만 명 | 31건 |
| 디지털 활용 배달주문형 | 약 1,269만 명 | 약 1,733만 명 | 284,413건 |

‘집·인테리어에서 2.3만’이라는 해석에는 화면 이동도 영향을 줬다. 이전에는 교집합 숫자를 보고 이름을 눌러도 전체 유형으로 이동했다. 현재 신호·하위 구성·산업 금액의 기본 행은 현재 조건을 보존한다. 전체 시장·전체 유형 이동은 별도 링크로 명시한다.

## 조사 기반 인구 보정

- [NIA 2024 인터넷이용실태조사 통계표](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=27870&cbIdx=99870): 표13(인쇄 p.23/PDF p.33)의 월간 인터넷 이용률, 표109(p.229/PDF p.239)의 인터넷 이용자 중 연간 쇼핑률을 연령·성별로 적용한다. 쇼핑은 인터넷 이용의 부분집합이다.
- [한국소비자원 2024 구매 행동 분석](https://www.ciss.go.kr/DATA/bbs/85/20240424094029637.pdf): 구매 전 정보검색 71%를 ‘구매 전 정보 검토’ proxy로 사용한다. 후기 71.4%는 **정보검색·품질 비교정보 경험으로 선별된 응답자의 비율**이다. 이를 사전검토 인구에 이식하는 가정을 공개한다. 전국 성인의 직접 후기 이용률이 아니다.
- 과거 뷰티·패션 서술 인구에 온라인 패션·화장품 거래액을 한 번에 배분하던 방식은 폐기했다. 현재는 `피부·헤어·뷰티 관리`(약 1,660만 성인, 미용 활동 cohort)와 `온라인 화장품 구매`(약 1,299만 성인, NIA 조건부 모델)를 분리한다. 2025 온라인 화장품 거래액 13.8153조원은 후자에만 배분하며, 전자의 all-channel 화장품 사용률·오프라인 구매는 미확보로 남긴다.
- 16개 연령·성별 인구 층, seed `20260906`, 층별 목표 건수 반올림을 사용한다. 원 서술의 긍정 근거를 우선 보존하며 조사 목표와 양립하지 않는 경우 일부가 제외된다. 미언급 소속과 결합은 모델 가정이다.
- 신중구매·후기 70세 이상은 조사 비율을 외삽하지 않고 서술 근거만 유지한다. NIA의 70세 이상 인터넷·쇼핑·품목 비율은 세부 고령층에 동일하게 적용하는 가정이다.
- 보정 인구의 Low/High는 최소 ±40%, 원 서술 1,000건 미만이면 ±50%다. 통계 신뢰구간이 아니다. 유효 표본은 원 서술 가중치로 계산하며 모델 배정 건수로 부풀리지 않는다.
- 그 외 시장·행동은 원 서술 인구 투영이다. 모든 유형의 수학적 일관성을 검사했지만 52개 유형 모두의 행동 유병률을 실측 검증했다는 뜻은 아니다. 원 추출의 holdout/lift는 **보정 전 추출 품질 기록**이다.

## 배분과 단위

각 원자 소비 항목의 공식 전국 거래액 × 선택 집단의 가중 소비 신호 합 / 해당 항목 전체 대상의 가중 소비 신호 합을 사용한다. 신호는 `paid`, `premium`, `paid_subscription`, `gear_upgrade`, `repeat_purchase`, `membership`이고 계수는 중앙 config에 있다. 관심 배수를 지출 배수로 복사하지 않는다. 배달·식품서비스는 간편식 관심 전체 대신 실제 `delivery_order` 신호로 배분한다.

성인 인구로 거래액을 배분하므로 인당 값은 **관련 성인당 연간 배분액**이다. 실제 구매자 평균·가구당 소비액이 아니다. 공동구매·미성년 소비를 성인 소비 결정 단위에 귀속시키는 가정이다. NIA의 자기보고 월평균 온라인 지출(표113)과 전국 거래액은 모집단·응답·거래 범위가 달라 동일한 소비액 관측으로 합치지 않는다. 배달 거래액과 배민·쿠팡이츠의 회사 매출도 같은 분자가 아니다.

온라인 기준의 직접 spend coverage는 0, monetary confidence는 Low다. Low 0.5× / High 1.7×는 세그먼트 배분 민감도이며, High는 항목별 전국 총액으로 제한한다. 전국 공표 기준액 자체는 Low/Base/High가 같다. 이는 공식 전국 통계의 오차나 회사 매출 시나리오가 아니다. `participationRate`는 실측 참여 분모를 확보하지 못해 null이다. 기존 음악만 별도 참여율 proxy를 유지한다.

같은 소비 항목 ID는 전체에서 한 번만 집계한다. 유형 합산은 금지하며 `isAdditive:false`, 검증된 독립 인구 분할만 합산 가능하다. 시장의 전체 기준을 볼 때는 그 시장 ID를 중복 필터하지 않는다. 선택 유형·연령 등 나머지 조건은 그대로 유지한다. 관련 인구는 조건에 해당하는 소비 프로필의 union으로 한 번만 센다.

## 재현·검증

원본 `atlas-index.json`, catalog, lexical oracle는 변경하지 않는다. `pipeline/calibrate_behaviors.py`가 보정 인덱스와 전수 전후 비교를 생성하며 `scripts/precompute-calibrated-cubes.mjs`가 1,396개 집계를 갱신한다. 모든 뷰는 같은 중앙 엔진을 사용하고 raw 프로필은 브라우저에 보내지 않는다.

```bash
python pipeline/calibrate_behaviors.py
./node_modules/.bin/tsc -p tsconfig.tests.json
node scripts/precompute-calibrated-cubes.mjs
npm test
node scripts/revision-sanity.mjs
npm run lint
npm run typecheck
npm run build
ATLAS_BROWSER_BASE=http://localhost:3002 node tests/browser-money-journey.mjs
```

`data/population-calibration-audit.json`은 모든 신호·유형·시장 전후 인구를, `data/revision-sanity.json`은 실제 52개 유형·20개 시장·산업별 금액/인구/관심 순위·Matrix 순위 차이를 기록한다. 일부 유형만 사례로 만든 데이터가 아니다.

화면은 인구·비중 중심의 신호 행, compact 인구/소비 strip, 연령·지역·생활 구성, 소비 항목 분해, 전국 기준의 전년 변화, Low/Base/High, 하위 집단과 출처 표로 구성했다. 전국 거래액 변화는 해당 세그먼트의 성장률로 표시하지 않는다. 상대 Index는 명시적으로 선택한 Matrix 모드와 상세 근거에서만 유지한다.
