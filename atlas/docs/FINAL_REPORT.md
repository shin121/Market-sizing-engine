# Nemotron Commercial Atlas — 최종 구현 보고

제품: 한국 소비자 전체에서 상업적 소비 유형과 산업을 오가며 구체적인 사업 가설을 발견하는 분석 워크벤치. 실행 주소와 최종 배포 상태는 산출물의 DELIVERY.md에 기록합니다.

1. **Nemotron 구조 분석** — 실제 9개 Parquet, 100만 고유 레코드, 26필드를 재분석했습니다. 원천은 합성 페르소나입니다. 인구·지역·가구 맥락은 구조화되어 있으나 소비 행동·욕구·채널은 서술에서 추출해야 합니다. 실제 소득·지출·거래·시계열은 없습니다. [감사](NEMOTRON_DATA_AUDIT.md)
2. **Commercial Archetype 추출 방식** — 53개 상업적 신호의 가중 동시출현 쌍에서 소비 메커니즘 후보를 생성했습니다. 인구·산업은 정의에서 제외하고 support, lift, 20% holdout 안정성, 최소 5개 비정의 Index, 유사도와 중복 제한을 적용했습니다. 221개 후보 중 품질과 다양성을 만족하는 유형을 선택했습니다.
3. **Archetype 수** — 52개입니다. 0/1 관측 membership을 사용하며 중복 소속을 허용합니다. 하나 이상 유형에 해당하는 인구 비중은 62.1%, 둘 이상은 33.3%입니다. 나머지를 강제로 분류하지 않았습니다. [유형 Dataset](../data/commercial-archetypes.json)
4. **대표 Archetype Top 30** — 이름·인구·비중·비정의 신호·산업 Index·JS·소비 관여·산업 수를 화면 개발 전에 검토했습니다. 계획 중심 수집몰입형, 후기 확인 신중구매형, 유료구독 프리미엄선택형 등 실제 조합 기반입니다. [Top 30 전체](ARCHETYPE_TOP_30.md)
5. **Archetype Size 산출 방식** — 20세 이상 989,509개 합성 표본을 2024.11 연령대×성별 16개 인구 기준, 44,105,000명에 보정했습니다. 추정은 조건을 만족하는 레코드의 가중합입니다. 19세 10,491건은 호환 기준 부재로 제외했습니다. 범위는 ±30%, 희소 집단은 ±50% 민감도입니다.
6. **Signal Index 계산** — P(신호｜선택 집단) ÷ P(신호｜전체 모집단)을 실제 교집합으로 계산합니다. 정의 신호는 별도 표시하고, 모르는 값을 1.0×로 채우지 않습니다. 정의에 이미 포함된 Matrix 관계도 독립 발견 추천에서 제외합니다.
7. **Distinctiveness 계산** — 정의 신호와 시장·인구 변수를 제외한 행동·욕구·채널의 Bernoulli Jensen–Shannon divergence입니다. 표시 점수는 JS×1500, 상한 100입니다.
8. **Consumption Intensity 계산** — 구매·유료 이용, 프리미엄, 유료 구독서비스 접점, 장비 구매, 반복 선택, 회원권·레슨의 상대 빈도를 결합합니다. 전체 기준 50이며 실제 지출·구매 빈도·heavy usage 지표가 아닙니다.
9. **Cross-industry Affinity 계산** — 시장 관심의 조건부 비중을 전체 비중과 비교합니다. 비중 >1%, Index ≥1.15인 산업 수와 강도를 계산합니다. 유형과 시장을 별개 Lens로 유지합니다.
10. **Discovery Radar** — 규모, 평균과의 차이, 소비 관여, 산업 연결, 작지만 강한 유형의 다섯 순위를 실제 중앙 지표로 계산합니다. 각 Top 3을 클릭해 전체 Dashboard로 이동합니다.
11. **Global Atlas 변경내용** — 네이비 탐색 메뉴·흰 분석 면·teal/purple 색상으로 재구성했습니다. 1440×900에서 유형 지도, 다섯 Radar, 인구 구성, 산업 분포와 기회 출발점이 함께 보입니다. 1920 화면도 확인했습니다. [화면](qa-atlas.png)
12. **Entity Dashboard architecture** — 공통 Estimate, Profile, Stat, AtlasContext를 기반으로 인구·신호·시장·욕구·관계·기회·하위 집단·근거 모듈을 조합합니다. 별개 페이지에 계산 로직을 복사하지 않습니다. [구조](ARCHITECTURE.md)
13. **Archetype Dashboard** — 규모·범위·점수, 연령·지역·가구 맥락, 최소 5개 구별 신호, 산업별 Index, 구매·신뢰·채널·욕구, 다른 유형, 기회, 세부 패턴과 근거를 표시합니다. [화면](qa-archetype.png)
14. **Market Dashboard** — 주요/고지수 소비 유형과 불편 신호를 첫 분석 화면에 배치했습니다. 관리 부담·디지털 부담·비용 등 불편 집단, 하위 시장, 소비 방식, 작은 강한 후보와 인접 산업으로 이어집니다.
15. **Segment / Signal Dashboard** — 실제 다조건 교집합, 상위 유형 및 산업 대비 비중 차이, 다른 신호와 관련 집단을 표시합니다. 집계 데이터 탭에서 모든 feature·인구특성·연관 유형의 인구, 원본 검출 건수, 비중, Index와 정의 여부를 확인합니다. 원문·UUID는 노출하지 않습니다.
16. **Mekko drill-through navigation** — 지도 셀은 전체 Dashboard의 canonical URL을 엽니다. 전체→수집형→반려동물→다른 구독 유형→욕구의 4단계 이상 탐색, breadcrumb, Back/Forward/reload를 검증했습니다. 큰 detail drawer는 제거했습니다.
17. **Relationship / Matrix / Opportunity integration** — 관계 노드의 분석을 페이지 안에 표시하고 전체 교집합으로 이동합니다. Matrix는 기존 조건에 두 축을 추가합니다. Opportunity는 현재 집단을 강조하고 최대 세 집단 비교를 URL에 유지합니다.
18. **Search** — 유형, 시장, 행동, 욕구, 채널, 관심과 생성 세그먼트를 검색합니다. 가격·수집·전문가·구독·반려동물·육아·여행 및 수집×반려동물 검색 경로를 확인했습니다.
19. **Browser Discovery Test** — 실제 10개 산업에서 시장→유형→강한 관계→의미 있는 Matrix 셀→기회 후보→다른 산업을 탐색했습니다. 수집형의 집 전시/정리, Pet 관리 부담, 배움·회복, 수집 커뮤니티 관련 가설을 얻었습니다. 금융의 희소 조합은 시장으로 범위를 넓혀 확인했습니다. [실제 여정과 사업 가설](BROWSER_QA.md)
20. **lint / typecheck / test / build** — lint, TypeScript, 22개 엔진 테스트, 14개 문맥 사례를 담은 2개 Python 테스트, production build가 통과했습니다. 70개 독립 SQL oracle, 1,396개 정확 집계 cube, 생성/서버 지표 일치, 원본 브라우저 경계와 빌드 Worker 페이지/API 응답을 검증했습니다. 전체·유형 페이지 axe 0 violations, 모바일 가로 넘침 0, 수정 후 새 브라우저 오류 0입니다.
21. **Known Limitations** — 합성 서술과 어휘 검출 기반이며 전체 precision/recall을 측정하지 않았습니다. 텍스트 양식과 공통 어휘가 관계를 강화할 수 있습니다. 인구 기준은 기존 출처 등록 자산으로, 이번에 공식 원표를 재수집하지 않았습니다. 지역은 독립 보정하지 않았습니다. 유형은 일부 소비자만 설명하며 실제 매출·WTP·성장·경쟁·미충족 수요를 입증하지 않습니다. 일부 좁은 조합은 관측이 부족합니다. 이러한 경우를 숨기거나 금융·추세 차트로 채우지 않았습니다.

상세 식, 가중치, 데이터 경계와 해석은 [DATA_AND_ESTIMATION.md](DATA_AND_ESTIMATION.md)에 있습니다. 이 구현의 결과는 추가로 조사할 사업 후보이며 사업성 확정이나 실제 소비 통계가 아닙니다.
